## Reflection
Enhancement one focuses on software design and engineering, emphasizing the development of projects through planning, designing, coding, and testing to achieve their intended functionality. During my computer science program, one of the first instances where I was able to demonstrate this skill is during the CS-360 Mobile Design and Programming course where the final project required the creation of an application that could store data in a database, provided the necessary features to create, read, update, and delete the entries in the database, and allow users to create and sign in to accounts to manage their data. For my project, I decided to create a weight-tracking Android mobile application that uses Java to build the front-end interface, back-end logic, and middleware to interface with a SQLite database. In the end, this artifact was one of the major points of the computer science program, as it allowed me creative control over most aspects of the design, planning, and coding processes and showed me the importance of these three processes for creating a successful project. 
The main reason I selected this artifact is due to the accomplishments I achieved with it initially. Not only was this one of the first full-stack applications I created, housing a front-end, back-end, and database, but it also demonstrated most of my skills and showcased much of what I learned throughout the computer science program. Creating the initial artifact required a lot of effort, but through the application of various skills such as planning, designing, and programming, the project was successfully created. Still, many ideas had to be omitted due to time constraints, and there are plenty of improvements that can be made after reflecting on the completed project. Choosing to enhance this artifact now provides me with the opportunity to rework this project and to show my improvement with the initial skills: planning, designing, and programming, along with other skills such as critical thinking and reading documentation. The enhancement's primary goal is to convert the weight tracker mobile application into a full-stack web application, enabling it to run on nearly any device with a compatible web browser and internet access. Having to redesign and plan the application to make it run using HTML, CSS, and JavaScript was arguably a bigger challenge than the initial creation of the mobile application. Still, through the improvement of my skills, this process was not as daunting, and through careful planning towards the structure of the project and considering the design of the web application to ensure it is compatible with various screen sizes, it helped to show that these skills have further developed after the completion of the mobile application. Additionally, improvements made during this enhancement, such as the addition of a goal type for the goal weight entry page, showcase my critical thinking skills by demonstrating that care was taken to identify potential improvements that could enhance the application's usefulness. Adding the option to choose a goal type, either loss, gain, or maintenance, allows the application to work for a wider audience, further improving its usefulness and capabilities. Other changes, such as adding cookies to store the user's ID for use elsewhere in the project, showcase both my critical thinking and my reading documentation skills. Considering improvements to handle the user's ID value and avoid passing information between components shows that care was taken to improve the application's performance as well. Successfully integrating this new tool is another showcase of a skill: reading documentation. To add this new, previously unused tool, its documentation needed to be read to determine the optimal approach to integrating it into the application. Converting the previous Android mobile application into a full-stack web application was the major accomplishment; other improvements in error handling and the potential weight goals make the application more versatile and are important in showcasing my growth. Overall, this artifact was one of the first full-stack applications I have made, and it had many improvements to be made, so using it for the first enhancement allows me to showcase my improvements in multiple skills and to adapt the application to make it more versatile and accessible to more devices. 
Initially, the plan for this enhancement was to accomplish the second and fourth course outcomes, as they involve providing proper documentation and using all available tools, resources, and best practices to achieve optimal results, respectively. The transfer from Java to JavaScript provided access to more resources that greatly benefited the project during development and in the final product itself, such as the use of Next JS to allow development solely in JavaScript as opposed to HTML, CSS, and JavaScript, and the use of a web browser database called IndexedDB to handle all user data. Even though the same features remain as in the initial artifact, their implementation is arguably better than the initial approach, as many improvements were made with the new tools and benefits available in JavaScript. Still, the fourth course outcome was not the only major improvement from this enhancement, as the second course outcome is also satisfied through the improved implementation of inline comments, and the addition of JSDoc API allows methods and functions to be described and explained directly within the code for use throughout the project. This API enables additional information to be quickly viewed in the IDE, making development easier by removing the need to locate functions to determine their purpose. It satisfies the second outcome by creating good documentation, so other programmers or developers can work on the project and quickly understand the approaches used throughout. Overall, while only two course outcomes were satisfied through this enhancement, there are two of the most important ones, as one involves creating a project in the most optimal manner possible by using the available tools, resources, and best practices, and the other ensures that regardless of who may access the project, it can easily be understood.
The initial creation of this artifact was an important experience in the computer science program, as it showed the effort required to plan, design, program, and test a project to ensure it functions properly. The most beneficial process was planning, as the creation of the artifact showed how easy it was to overlook issues and how doing so could create major problems in the rest of the project. Thus, before starting this enhancement, time was devoted to the planning stage to ensure that all aspects were accounted for and that most issues were addressed as soon as they were discovered. In doing so, this enhancement showed me how important it was to fix issues when they are found since it requires the least amount of time and effort. Had the issues been left unresolved, they would have led to larger, more time-consuming issues that would have needed to be fixed in subsequent enhancements. Taking the time to address them right away not only fixes the issue quickly but also helps with future planning, as it ensures that the mistake or issue that led to it will not be made again. Still, the biggest challenge during this enhancement was the design process, as the goal was to provide users with a similar user experience regardless of the device they used to access the web application. To achieve this, multiple designs for the same page were required to ensure that, regardless of screen size, the application could dynamically adjust to the design most appropriate for the user's device. Having to create multiple versions of the same design, with slight variations to accommodate different screens, was a time-consuming process and led to challenges such as determining which screen sizes to plan for and how these variations should affect the design. Ultimately, while the design process was challenging, the time and effort spent were worth it, as it ensured that all aspects of the design were accounted for and that users would have a good experience with the application regardless of their device.
