**Hello**, my name is Cristiano Miranda and I am currently working towards becoming a web developer. This site houses the knowledge I have learned while completing the SNHU computer science program.

## My SNHU Computer Science Journey

Completing the SNHU computer science program has shown me how much effort goes into creating well-made programs and the various skills needed to do so. Each step of the creation process, or the software development life cycle, is a crucial stage that needs the proper time and effort to ensure its associated aspects of the project are properly created, managed, and implemented. After completing many course projects and independent projects during this journey, my biggest takeaway was how important specific skills were in creating successful projects. Most of these skills were ones I learned right away but continued to develop and improve throughout the computer science program. These skills included reading documentation, planning, designing, programming, critical thinking, problem-solving, and above all, communication. One of the first skills I learned was planning and programming, as even in the initial courses, developing a plan to solve a task was necessary, along with writing the code to solve the problem and debugging any issues that may occur during the process. The work that best emphasized my growth was my CS-300 Analysis and Design course, which involved implementing data structures, deciding which data structures were most appropriate for a given task (such as storing related course data), and developing the solution using the determined plan. Completing this course required careful planning and communication so the professor could understand the decisions behind the chosen data structure and why it was the optimal choice. Failing to implement the appropriate data structure would have resulted in work that failed to meet the requirements, and without a carefully thought-out plan, it would have been impossible to justify the decision. This process showed me how important planning is to ensure all involved parties in creating the program are on the same page and working toward the same goal. Still, development was another aspect that greatly helped me build my programming skills. Even though a general plan was created, adapting it to a specific programming language using that language's available techniques and approaches is another major part of the creation process. Additionally, errors often occurred during runtime that needed to be addressed and fixed. This occurred during this project, and it helped me improve my programming skills by learning the best approaches to solving bugs and determining their root causes. Programming and planning were two of the first skills I developed, and I improved them to the point that, regardless of the goal, task, or tools, I can develop a well-thought-out plan and apply core programming principles to create it in almost any programming language.

Beyond planning and programming, the other specific coding skills I learned at the start were reading documentation and problem-solving, and these were some of the most important skills during this program. While core principles of programming carry over regardless of the programming language, syntax, integration, use of various tools, and approaches to solving problems are not consistent across languages. Thus, being skilled at reading documentation by having the ability to read through and understand any required documentation was a key skill that helped me complete the various tasks in the different coursework. Even when the programming language changed, being able to read documentation and determine how to apply a tool correctly or write the appropriate syntax made it possible to meet the goal, regardless of my initial familiarity with the programming language or tool. This skill was also essential in my continued learning of new material and subjects, as it allowed me to use various documentation and determine how software worked, functioned, and what the best practices were. Problem-solving mirrors this principle of reading documentation as well. Even when I encountered unfamiliar challenges or issues, using past knowledge and learning more about the new issue were essential steps in helping me find the necessary solution, and learning to act this way was a direct result of my problem-solving skills. One of the best examples of both of these skills was in my CS-370 Current/Emerging Trends course, where we created an artificial intelligence system that could solve a maze. Although I had no initial understanding of how the system worked, I read the provided documentation and fully understood how the advanced algorithms within the system functioned. Using this knowledge, I completed the work to finish developing the system's learning module, allowing the agent in the maze to discover the optimal solution through a trial-and-error approach. By applying what I had just learned and drawing on my previous knowledge of algorithms, I integrated the necessary logic to solve the maze.

The final two skills, critical thinking and communication skills, greatly surprised me when I first discovered how important they are in programming. While other skills were easy to understand in terms of their purpose, these two skills were peculiar at first because they were soft skills that did not seem to pertain to the main aspects of programming. However, after learning these skills and being able to apply them directly in projects, it became clear that even though they did not pertain to the direct coding process, they were still essential in other areas. One of the best examples of these skills was my CS-305 Software Security course, which emphasized preventing software security threats by implementing proper security practices within an application and performing security checks throughout the development process. Of these skills, critical thinking was one of the most exercised during this coursework, as unlike my usual approach of solving known issues, this work required me to think about how a program could be flawed. Discovering these issues rather than solving them showed me how flawed my initial approach to security was and helped me focus on further developing this critical thinking skill so I can better identify vulnerabilities and potential issues at all stages of the development process. This skill helped me discover issues I would have easily overlooked and develop more secure applications. Still, while critical thinking was one of the main skills, communication was another that shined during this course. Even though discovering potential issues helped during the course, it also highlighted how important it is to communicate with a team to ensure everyone is following best practices and is aware of any discovered vulnerabilities. While other courses introduced and emphasized team communication to ensure everyone was on the same page and following the same procedures, this course showed why communication is required and is one of the most important skills in programming. Failing to communicate with team members could easily lead to major problems beyond completing a project, as poor communication can create vulnerabilities that harm users. Completing this computer science program has shown me how important certain soft skills are in programming, as they are essential for solving problems beyond the code and for improving one's capabilities when working on a team and identifying potential issues in a project.

## Artifact Introduction

I continue to develop all the skills mentioned and will do so throughout my career. This desire to improve and keep learning has continued to prove beneficial in creating better products. For instance, in my CS-360 Mobile Architecture and Programming course, one of the last courses I completed during my program, I developed one of my most important applications: a weight-tracking mobile application. This software artifact is a weight-tracking mobile application that allows users to track their weight over time and set goal weights they can work toward, and it uses user accounts to associate users with their recorded information. The initial artifact was a major achievement in my journey, as it was my first mobile application, and it was one of the most involved projects I had created at the time, as it contained a graphical user interface, stored user data persistently, and was capable of running on almost any Android mobile device. While previous projects have had these elements, such as databases, back-end logic, security measures, and a front-end interface, this software artifact was one of the first course projects in which I integrated all parts into a single project and had control over the whole process. Rather than having instructions or notes on the best approaches to completing the tasks, I had to plan and design all aspects of the application. Completing this artifact was a major accomplishment and helped showcase my improvement over the program. Still, I wanted to make many improvements and address some oversights, so this software artifact became the sole focus during the various enhancements in my Final Project for the Capstone course. The enhancements completed on this artifact again showcase my continued learning and improvement in the various skills mentioned, as they address many of the issues I discovered within the artifacts after reviewing the project. Additionally, each enhancement builds on the last, showing continued improvement and skill development and culminating in the final enhancement, which reflects my education, skills, and current capabilities after completing the computer science program. My goal with these enhancements was to show how much I learned from this program and how continued skill development has allowed me to successfully create entire applications that are manageable, collaborative, secure, and use proper techniques and design choices.
